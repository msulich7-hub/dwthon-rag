# SPEC: CRM 2027 — Phase 2 (execution & operations)

**Status:** in progress  
**Depends on:** `2027-05-23-crm-2027-product-foundation.md` (Phase 1)

## Scope

| Item | Deliverable |
|------|-------------|
| Voice execution | `POST /api/crm_2027/voice-execute` → `customers.interactions.create` (tasks/notes) |
| At-risk persistence | Entity `crm_2027_deal_risk_flags` + upsert command |
| At-risk API | `GET /api/crm_2027/at-risk-deals` |
| At-risk UI | `/backend/crm_2027/at-risk` + sidebar menu injection |
| Autonomy worker | `crm_2027:risk-scan` queue worker + `POST /api/crm_2027/risk-scan` trigger |
| AI tool | `crm_2027.execute_voice_intent` (mutation via command bus) |

## Acceptance

1. Voice transcript creates a task interaction when `entityId` or resolvable contact name is provided.
2. At-risk dashboard lists flagged deals with reasons.
3. Risk scan worker upserts flags; manual API can enqueue scan.
4. `yarn generate` picks up entities, commands, routes, worker, backend page.
